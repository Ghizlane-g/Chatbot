# 🟧 Orange Digital Center Morocco – AI Chatbot

##  Project Overview

An AI-powered chatbot developed for the **Orange Digital Center (ODC) Morocco** to answer questions about digital training, technology, entrepreneurship, and ODC programs.

## Features

*  Interactive chatbot
*  LLM-based responses
*  French responses
*  Conversation history
*  Streamlit interface
*  Secure API key management with `.env`

##  Technologies

* **Python**
* **Streamlit** – user interface
* **LangChain** – LLM integration
* **Groq** – LLM inference platform
* **GPT-OSS-120B** – language model

##  Project Structure

```text
ODC_chatbot/
├── chatbot.py
├── interface.py
├── requirements.txt
├── .gitignore
└── README.md
```

##  Run the Project

```bash
pip install -r requirements.txt
streamlit run interface.py
```
##  Project Objective

The objective of this project is to demonstrate the development of a conversational AI application using a Large Language Model (LLM), while providing a simple and user-friendly interface for Orange Digital Center Morocco.
